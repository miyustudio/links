# Miyu Studio — página de enlaces
1. Edita links.js con tus URLs reales. Los catálogos sin enlace aparecen como Pronto; WhatsApp y redes sin URL se ocultan.
2. Crea un repositorio público en GitHub (por ejemplo miyu-links) y sube todos los archivos de esta carpeta a la raíz.
3. En Settings > Pages, selecciona Deploy from a branch, main, / (root), Save.
4. Abre la URL que GitHub Pages muestra y comprueba todos los enlaces. Luego colócala en la biografía de Instagram.
Puedes subir PDFs a una carpeta catalogos y usar la URL completa publicada de cada PDF en links.js, o usar enlaces públicos de Google Drive. No subas información privada.
El logo es un recorte de tu captura; puedes sustituir logo.png por tu original cuadrado de alta resolución. Colores en style.css. No requiere instalar dependencias.
